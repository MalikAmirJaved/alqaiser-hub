                         1. SYSTEM OVERVIEW
================================================================================

Al Qaiser BOS is a complete Business Operating System that manages:

  - Human Resources (employees, payroll, leaves, shifts, assets)
  - Inventory (products, stock, warehouses, purchase orders, POS)
  - Sales (leads, quotes, invoices, customers)
  - Finance (accounts, journal entries, invoices, expenses, budgets, forecasting)
  - AI Monitoring (CCTV, camera feeds, alerts)
  - Settings (company profile, users, permissions, departments, designations)

URL: http://192.168.88.51:3000

  Technology:
  - Backend:  Django 6.0 + Django REST Framework + PostgreSQL + Redis
  - Frontend: Next.js 14+ (App Router) + React 19 + TypeScript + Redux Toolkit + TanStack Query
  - Auth:     JWT (HttpOnly cookies) with role-based access control (RBAC)
  - Realtime: WebSocket notifications + Celery background tasks + HLS streaming
  - Streaming: FFmpeg RTSP-to-HLS for CCTV camera feeds

---------------------------------------
  5.3 Payroll
---------------------------------------

  URL: http://192.168.88.51:3000/hr/payroll

  Purpose: Process and manage employee salaries.

  IMPORTANT: Payroll operates on a PREVIOUS MONTH basis.
  When you open payroll, the default month selected is the PREVIOUS month
  because most companies pay salaries after the month has ended.

  ┌─────────────────────────────────────────────────────────────────┐
  │              SALARY CALCULATION RULES                            │
  ├─────────────────────────────────────────────────────────────────┤
  │                                                                 │
  │  RULE #1: Fixed 30-Day Month                                   │
  │  ─────────────────────────────                                  │
  │  Days in month = 30 (FIXED)                                    │
  │  This is a system rule. If you need to change this,            │
  │  contact support.                                               │
  │                                                                 │
  │  RULE #2: Pro-Rated Salary for Mid-Month Joins                 │
  │  ──────────────────────────────────────────                     │
  │  If an employee joins DURING the payroll month:                 │
  │                                                                 │
  │    prorated_days = 30 - joining_day + 1                        │
  │    factor = prorated_days / 30                                  │
  │    base_salary = original_salary * factor                       │
  │                                                                 │
  │  The +1 means the joining day itself is PAID.                   │
  │                                                                 │
  │  Example 1: Employee joins on 1st                              │
  │    prorated_days = 30 - 1 + 1 = 30                            │
  │    factor = 30/30 = 1.0                                        │
  │    Base Salary = 30,000 x 1.0 = 30,000 (FULL salary)          │
  │                                                                 │
  │  Example 2: Employee joins on 10th                             │
  │    prorated_days = 30 - 10 + 1 = 21                           │
  │    factor = 21/30 = 0.70                                       │
  │    Base Salary = 30,000 x 0.70 = 21,000                       │
  │    (Paid for days 10 through 30 = 21 days)                     │
  │                                                                 │
  │  RULE #3: Leave Deductions                                     │
  │  ────────────────────────                                       │
  │  Leave types and conversion:                                    │
  │    2 short leaves = 1 half leave                               │
  │    2 half leaves  = 1 full leave                               │
  │                                                                 │
  │  Full leave deduction calculation:                              │
  │    total_full_leaves / 30 * monthly_salary                     │
  │                                                                 │
  │  RULE #4: Final Salary Formula                                 │
  │  ─────────────────────────────                                  │
  │  Base Salary = Base Salary                                     │
  │               + Compensation (allowances)                       │
  │               - Loan repayment                                  │
  │               - Leave deductions (from Rule #3)                 │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘

  Payroll Workflow:
    1. Go to Payroll page
    2. System auto-selects previous month (can be changed)
    3. Click "Process Payment" of user that want pay salary
    4. System calculates salary for each employee:
       - Base salary (pro-rated if joined mid-month)
       - Add compensation/allowances
       - Deduct approved leaves
       - Deduct loan repayments
    5. Review the preview
    6. Process/Finalize the payroll
    7. Employee salary is recorded

  Stats:
    - Total payroll amount
    - Processed vs pending
    - Average salary

---------------------------------------
  5.4 Leave Management
---------------------------------------

  URL: http://192.168.88.51:3000/hr/leave

  Purpose: Manage employee leave requests and approvals.

  Actions:
    CREATE   - Apply for leave (employee or admin)
    APPROVE  - Confirm/reject a leave request
    REJECT   - Reject a leave request

  How to Apply for Leave:
    1. Click "Apply for Leave" button
    2. Select the Employee (who is requesting leave)
    3. Select Period Type:
       - Short Leave  (a few hours)
       - Half Day     (half a day)
       - Full Day     (entire day)
    4. Select the Date
    5. Add a Reason (required)
    6. Click Create

  Approval Tab:
    - All pending leave requests appear here
    - For each request, you can:
      * Confirm (approve) - leaves are counted in payroll deductions
      * Reject - leave is denied
    - Once confirmed, the leave affects salary calculation

  How Leaves Affect Payroll:
    - Approved leaves are converted using the deduction rules
    - 2 short leaves = 1 half leave
    - 2 half leaves = 1 full leave
    - Full leave deduction = (total full leaves / 30) x monthly salary

  Stats:
    - Total leave requests
    - Pending approval count
    - Approved vs rejected

                  11. PERMISSION & ACCESS CONTROL
================================================================================

  The system uses a Role-Based Access Control (RBAC) system.

  Permission Format: MODULE:resource:action

  Available Modules:
    HR, INVENTORY, FINANCE, SALES, AI_MONITORING, NOTIFICATIONS, SETTINGS

  Available Actions:
    view, create, update, delete, approve, assign, export, import,
    process, confirm, receive_goods, complete_sale, etc.

  Examples:
    HR:employee:view          - Can view employees
    HR:employee:create        - Can create employees
    HR:payroll:process        - Can process payroll
    HR:leave:approve          - Can approve leaves
    INVENTORY:product:create  - Can create products
    FINANCE:payment:pay       - Can record payments
    SALES:lead:convert        - Can convert leads to quotes

  Roles:
    - COMPANY_ADMIN: Has all permissions (bypasses checks)
    - BRANCH_ADMIN: Configured per branch
    - STAFF: Configured per user

  How Permissions Work:
    1. User logs in -> system loads their permissions
    2. Permissions are stored in Redux (frontend state)
    3. Sidebar filters menu items based on permissions
    4. Each page checks permissions before showing actions
    5. Backend validates permissions on every API request
    6. Changes propagate in real-time via WebSocket

  To Configure Permissions:
    1. Go to Settings > Permissions
    2. Select a user
    3. Assign a role
    4. Add/remove individual permissions
    5. Changes take effect immediately

================================================================================
                    14. TROUBLESHOOTING & FAQ
================================================================================

  Q: I can't see a module in the sidebar.
  A: Your permissions may not include that module. Contact your admin
     to grant access via Settings > Permissions.

  Q: I'm getting "Unauthorized" errors.
  A: Your session may have expired. Log out and log back in.
     If it persists, clear your browser cookies.

  Q: The page shows "Access Denied".
  A: You don't have permission for that specific action.
     Contact your admin to update your permissions.

  Q: Payroll shows the wrong month.
  A: Payroll defaults to the previous month by design.
     You can change the month using the month selector.

  Q: Stock shows negative numbers.
  A: This can happen if sales exceed available stock.
     Check stock adjustments and transfer history.

  Q: Notifications are not showing.
  A: Ensure WebSocket connection is active.
     Check if notifications are enabled in your browser.

  Q: How do I reset my password?
  A: Ask your admin to edit your user account in
     Settings > Users and set a new password.

  Q: How do I add a new employee?
  A: Go to HR > Employees > Create Employee.
     Fill in all required fields and save.

  Q: How do I process payroll?
  A: Go to HR > Payroll > Generate Payroll.
     Select the month, review the preview, then process.

  Q: How do I approve a leave request?
  A: Go to HR > Leave > Approval tab.
     Click Confirm or Reject for each request.
